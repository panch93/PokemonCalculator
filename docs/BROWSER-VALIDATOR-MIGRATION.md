# Browser-compatible Pokémon Showdown validator migration

## Current state

The browser validator now calls the official Pokémon Showdown `TeamValidator` in a Web Worker. The adapted upstream source and base-generation data for Gen 1–9 are bundled under `src/lib/showdown-official/`; static imports replace Node filesystem-based data loading. No backend or API route is required, and `@smogon/calc` remains unchanged.

## Supported formats

User-supplied teams in formats using the official base `gen1` through `gen9` mods are enabled. The bundled source snapshot includes upstream rule-table expansion, species/item/ability/move checks, learnset and source-generation checks, and format-specific validation hooks from the upstream validator. Formats requiring other mods, generated teams, National Dex/custom rules, or custom mods outside the bundled base-generation mods remain unverified. The validator must return `valid: null` for those formats.

The format picker may fetch current upstream format metadata. That metadata is never evaluated as code; when ruleset metadata is available, the worker compares it with the bundled format and returns unverified if it differs. It cannot replace the executable rules bundled with the validator. The validator's rules/data revision is reported by the worker.

## Static hosting constraints

The deployed site remains a static export. The validator executes in a browser Web Worker; it does not require a Node server, Next.js API route, or remote legality endpoint. Upstream TypeScript source is reviewed and bundled, not fetched and evaluated at runtime.

## Updating upstream

1. Review the weekly monitoring issue generated by `.github/workflows/monitor-showdown-validator.yml`.
2. Select a specific upstream commit and regenerate the source/data snapshot.
3. Review Node-specific APIs and changes to TeamValidator dependencies before updating the browser adapters.
4. Add differential fixtures against the same upstream revision for newly supported rules or mods.
5. Run `npm run typecheck`, `npm test`, and `npm run build` before deployment.
6. Do not enable a new format mod until its full data and rule dependencies are bundled and tested.

See `MILESTONE_4_OFFICIAL_BROWSER_TEAMVALIDATOR.md` and `src/lib/showdown-official/UPSTREAM-SNAPSHOT.md` for scope and provenance.
